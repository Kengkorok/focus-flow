# Focus Flow 🎯

A clean, minimal Pomodoro timer for staying focused and productive.

## Features

- **Pomodoro Timer**: 25-minute work sessions with 5-minute breaks
- **Task Management**: Keep track of your daily tasks
- **Session Tracking**: Monitor sessions completed and time tracked
- **Persistent State**: Your tasks and stats are saved locally
- **Desktop Notifications**: Get notified when sessions complete
- **Responsive Design**: Works on desktop and mobile

## Usage

1. Open `index.html` in your web browser
2. Start a work session by clicking the **Start** button
3. Add tasks for the current session
4. Check off tasks as you complete them
5. When the timer reaches zero, take your break!

## How It Works

- **Work Phase**: 25 minutes of focused work
- **Break Phase**: 5 minutes to rest and recharge
- **Local Storage**: All data is stored in your browser's localStorage

No server required. No sign-ups. Just pure focus.

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge) with localStorage support.
